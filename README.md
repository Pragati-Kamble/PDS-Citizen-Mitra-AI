PDS Citizen Mitra – AI Chatbot

An AI-powered chatbot designed to help citizens understand India's Public Distribution System (PDS), ration card rules, food grain entitlements, and grievance procedures.

About the Project

PDS Citizen Mitra aims to make government food distribution information easier to access. It allows citizens to ask questions in natural language and receive helpful responses about ration-related policies and services.

Objectives

- Simplify access to PDS information.
- Help citizens understand ration card rules and food grain quotas.
- Provide guidance on common ration distribution questions.
- Help users find official grievance and support channels.
- Make government policy information easier to understand.

Key Features

- AI Chatbot: Answers citizens' questions about PDS-related topics.
- Policy Guidance: Helps explain ration card rules and entitlements.
- Citizen Support: Provides information about grievance procedures and helplines.
- Web Interface: Offers a simple interface for interacting with the chatbot.
- Government Information: Designed to support answers grounded in official policy documents.

Getting Started

Prerequisites

- Node.js and npm, if required by your project
- A Google Gemini API key
- A web browser

Installation

1. Clone the repository:
   
   git clone https://github.com/Pragati-Kamble/PDS-Citizen-Mitra-AI.git

2. Open the project directory:
   
   cd PDS-Citizen-Mitra-AI

3. Install dependencies if a "package.json" is present:
   
   npm install

4. Configure your Gemini API key using a server-side environment variable. Never commit your real API key to GitHub.

5. Start the application using the start command specified in your project's "package.json" or README.

Official Support

- National PDS Helpline: 1967 (availability may vary by state)
- Consumer Helpline: 14445 (verify current availability before relying on it)

For official rules and entitlements, consult the relevant government PDS portal and your state's food and civil supplies department.

Security

- Never upload ".env" files or API keys.
- Keep API credentials on the server, not in browser storage or frontend JavaScript.
- Do not upload private citizen information.
